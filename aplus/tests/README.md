# Pruebas de metadatos

Sirve la carpeta raíz de la aplicación mediante HTTP o HTTPS y abre:

`/tests/metadata-tests.html`

La prueba se ejecuta completamente en el navegador y muestra `ALL TESTS PASSED` cuando termina correctamente. No carga el modelo de inteligencia artificial.

Las imágenes de `fixtures/` son muestras mínimas de 16 × 12 píxeles creadas exclusivamente para verificar que JPG, PNG y WebP siguen decodificándose después de insertar XMP.
